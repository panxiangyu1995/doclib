# 进度时间线（progress.md）

> 时间线只叙述，不另立状态；状态事实源见 [feature-map.md](feature-map.md)。每次开发会话补一条记录：日期、关联 `.plan` 文档、完成条目、涉及卷、状态变化、教训处置。

- **YYYY-MM-DD**
  - 关联 .plan：`.plan/YYYY-MM-DD/<名称>.md`
  - 完成条目：feature-map #N（一句话）
  - 涉及卷：TODO
  - 状态变化：#N planned → implemented
  - 教训: 无（理由）或 95-lessons YYYY-MM-DD · 标题
