# 会话档案区（98-sessions）

> agent 对话原始记录档案区——蒸馏层（规划载体）之外的原始层，供长期回查。

## 定位

本区存放 agent 会话的对话导出记录（transcript），是图书馆对规划载体双轨边界的白名案例外：

- 规划载体是**蒸馏层**——沉淀目的、问题点、研究结果、方案与验收标准；
- 本区是**原始层**——完整保留对话中的人机往来与关键工具调用，蒸馏遗漏时可回查。

两者互为校验：规划写漏了可回查本区原始记录；本区文件只增不改（档案语义）。

## 命名与登记规范

- 文件名：`<slug>-<yyyymmdd>-<NN>.md`——slug 与对应规划文档一致；同一规划跨多会话以 NN 序号区分。
- frontmatter 五要素：`type: transcript`、`tool`（opencode/claude-code/codex/aider/…）、`session-id`（工具原生会话 ID）、`date`（导出日期）、`plan-slug`（关联规划 slug）。
- 双向关联：对应规划文档头部登记本区导出文件名；本区 frontmatter `plan-slug` 回指规划。

## 注意事项

- 本区豁免文体门禁与污染检查——对话原文不改写，保持原始性。
- 导出前自查敏感信息（密钥/token/凭据）——对话中可能出现过，落馆即入 git 历史。
- 会话记录在部分工具侧默认 30 天自动清理，导出落馆是唯一保久手段。
