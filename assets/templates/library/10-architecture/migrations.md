# 数据库迁移账本（migrations）

> 实体文件在代码区 `migrations/`，本卷是**治理账本**：全局唯一取号出处 + 状态登记。目的：agent 长期开发中迁移治理不失控。

## 命名规则

`migrations/NNN_YYYYMMDD_<slug>.sql`

- `NNN`：全局三位递增序号，**执行顺序的唯一权威**（同日多迁移不冲突）；从账本取号，禁止凭空编号
- `YYYYMMDD`：创建日期（人读与审计）
- `<slug>`：小写连字符语义名（如 `add-users-table`）

## 纪律（agent 必读）

1. **取号**：新迁移必须从下方账本取下一个序号；账本是唯一编号事实源
2. **不可变**：状态为 applied 的脚本禁止修改/删除（漂移检测会抓到违改）；错误用新增补偿迁移修复
3. **forward-only**：默认不写 down 脚本；"回滚" = 新增补偿迁移，账本记 rolled-back
4. **登记即完成**：迁移文件落盘与账本登记是同一步；未登记 = 未完成（实时同步原则）
5. **数据风险**：破坏性变更（删列/改类型/锁表/大表重写）必须在账本"数据风险"列显式标注并写缓解措施
