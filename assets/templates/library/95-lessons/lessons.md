# 经验教训（95-lessons）

<!-- doclib:lesson-source-epoch: -->

> 只记可迁移的经验，不记流水账。**踩坑当下**在 .plan 规划文档「失败尝试与踩坑」节记一行现象（一行制，防会话中断丢失上游素材），**会话收尾**蒸馏为本节四段条目并入档（实时同步原则）。条目格式：

```
## YYYY-MM-DD · 标题
- 现象：
- 根因：
- 解决：
- 规避：
- 来源：<.plan/缺陷记录/验收档案路径 或 progress 引用>（epoch 后必带——check「教训来源缺失」执法，路径须真实存在防幻觉）
```
