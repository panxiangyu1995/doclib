# 推广视频字幕文案

## 字幕规范

| 项 | 规则 | 执法 |
| --- | --- | --- |
| 单句长度 | ≤18 字（过长换行会顶破 safe-zone） | `doclib check` 文体门禁不查；靠 `hyperframes check` 的重叠检测兜底 |
| 单幕句数 | ≤3 句 | 同上 |
| 字号 | ≥28px（工具的「可读下限」判定） | `hyperframes check` → `text_below_floor` |
| 位置 | safe-zone 1400 宽、居中、底 100px | `hyperframes check` → `content_overlap` |
| 终端画面 | **只呈现 ASCII**（本机无 CJK 等宽字体，中文入框必错位）；中文解释一律移到字幕层与右栏 | 设计约束，见 [production.md](production.md) |
| 数字 | 与 [storyboard.md](storyboard.md)「数字来源表」逐行一致 | 发版前复跑 |
