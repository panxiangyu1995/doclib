# 复原基准测试指南（Reconstruction Benchmark）

> 图书馆完备度无法自证——内容再全面也难以证明"特别全"：写文档的人不知道自己漏了什么（未知的未知），只有只凭文档做事的复原者能显形缺口。
> 本指南沉淀 2026-10-19 方法论讨论（用户拍板 + 五项补强），规格见 PRD F14（v0.19）。执行本指南前请先读 PRD F14 与 F3。

## 原理

**复原即基准测试**：给多个现有开源项目建图书馆 → 通过图书馆从零复原开发这些项目 → 对比原仓库与复原仓库的差异 → 差异即图书馆缺陷显影 → 对症下药完善 → 回归重试。这是文档领域的 TDD：图书馆是代码，复原是测试，差异是失败用例。

多项目交叉验证防过拟合：单项目校准会让基线迁就该项目特性；**多项目共性缺陷**才是 12 卷基线/登记簿 schema 演进的实证依据（裁决 PRD Q15/Q25/Q26）。

## 操作闭环（七步）

1. **选基准项目**：按下方准入标准挑选，登记入复原档案
2. **建馆**：对原仓库执行 doclib-build（按 skill 方法论），`doclib snapshot` 固化基线
3. **隔离复原**：新环境执行 `doclib plan --rebuild`，复原者**只读图书馆**（信息隔离铁律，F3）；见"污染防护"
4. **同题共答**：同一套验收标准在原仓库与复原仓库**双跑**，逐条对比行为结果；结构对齐度由 agent 评审辅助
5. **缺陷分类**：每个差异按四分类入账（见下）
6. **对症下药**：内容缺陷回灌补账；结构缺陷触发基线/PRD 演进；表述/验收缺陷改 skill 与模板
7. **回归重跑**：图书馆结构版本变更后必跑（见"回归触发"）

## 基准项目准入标准

- **体量**：小中型（单 agent 数日可复原）——CLI 工具、小型库、小型应用；不选框架级巨物
- **多样性**：覆盖不同领域（后端服务/CLI/前端应用/数据处理）——不同领域暴露不同卷的盲区（如 80-design 只有前端项目能测）
- **生态**：宽松协议（MIT 等）、活跃维护（对比有基准）、入口清晰
- **切片复原**：大项目按功能切片部分复原，局部缺陷同样可暴露

## 同题共答（对比分层）

| 层级 | 对比物 | 判定 |
| --- | --- | --- |
| 行为层（主） | 同一套验收标准双跑（原仓库 vs 复原仓库），逐条对比结果 | 不一致 = 图书馆缺陷 |
| 结构层 | 模块职责/数据流/依赖对齐度（agent 评审） | 偏差 = 结构叙述不足 |
| 字节层 | **不对比**——代码风格/命名/quirk 是设计值（PRD 非目标） | 无意义 |

## 缺陷四分类账（每个差异必须分类）

| 类别 | 判定 | 行动 |
| --- | --- | --- |
| 内容缺陷 | 该项目图书馆漏写某功能 | 项目级补账（回灌流程，PRD Q6） |
| 结构缺陷 | 某类知识在 12 卷/登记簿 schema **装不下** | 产品级：触发基线/PRD 演进——多项目共性暴露的结构缺陷是基线演进的实证依据 |
| 表述缺陷 | 写了但复原者读出歧义 | skill 方法论改进（怎么写才算清楚） |
| 验收缺陷 | 验收标准不可执行/结果不可比 | 30-features 模板改进 |

## 复原档案（每基准项目一份）

- 基准项目标识与准入记录（领域/体量/协议）
- BUILD 基线版本号（snapshot id）
- REBUILD-LOG.md（复原全过程留痕 + **复原者身份**）
- 差异清单（同题共答结果）
- 缺陷分类账（四分类逐项）
- 修复记录（回灌/演进/改进动作与对应 PRD/基线变更）

## 污染防护（关键，易忘）

- 建馆与复原必须使用**不同会话/不同实例**——**理想为不同模型**
- 失效模式：同一 agent 先建馆再复原，先验知识（记忆中的源码）让复原"过顺"，缺陷不暴露，校准失真
- REBUILD-LOG 必须记录复原者身份（会话/实例/模型），用于审计隔离有效性
- 若条件所限只能同模型，至少保证全新会话且不向复原会话透露任何源码细节

## 回归触发

- 图书馆**结构版本变更**（基线分类法/登记簿 schema/条目五要素调整）→ 该基准项目**必跑**完整回归
- 图书馆**内容更新** → 抽查跑（受影响功能切片）
- 回归结果对比历史复原档案：复原度得分不回退为通过；回退 = 本次"改进"引入了退化，须复盘

## MVP 实验清单（首轮）

1. 拍板首个基准项目（PRD Q31，拟用户最熟悉领域、小中型、宽松协议）
2. 跑通全闭环 1 次：建馆 → 隔离复原（不同模型/实例）→ 同题共答 → 缺陷四分类 → 回灌/改基线
3. 产出首轮复原档案与复原度得分；结构缺陷汇入 PRD 演进
4. 复盘方法论本身（本指南修订），再扩基准库至 3–5 个领域样本
